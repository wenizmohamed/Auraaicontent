## Performance gap analysis (P1)

The 67 score is dominated by main-bundle download cost. Top remediations ranked by ROI:

1. **Lazy-load `recharts` + `framer-motion`** — both are pulled in eagerly today even on the login route. They're only needed on Dashboard / ContentCalendar / ContentReview. Splitting via `React.lazy()` + dynamic `import()` should drop initial JS by ~250 KB gzip.
2. **Route-level code-split** — currently every page (Dashboard, ContentCalendar, Profile, ApiKeys, etc.) is in `index-*.js`. Move each to a per-route lazy chunk.
3. **Pre-connect to Google Fonts CDN** — `<link rel="preconnect" href="https://fonts.gstatic.com">` in `index.html` shaves ~80ms TTFB on the font request.
4. **`font-display: optional`** for non-critical Libre Bodoni weights (italic 400-500) — already swap-display, but optional removes the brief Libre Bodoni-flash on slow networks.

Estimated effort: 1 parallel session for items 1-3.
